# YouTube Skipper v2.0.2

## Changed

- Explain SponsorBlock's receipt of the video hash prefix and IP address in the popup and privacy notice.

## Install

Download `youtube-skipper.zip`, extract it, and load the extracted folder through `chrome://extensions` in Developer mode.
